Daily Signal / Position Decision 화면

이 화면은 백테스트 결과가 아니라 실제 Daily Signal 실행 결과를 보여줌. Daily Signal은 최신 feature 기준 매수 후보이고, Daily Position Decision은 실제 보유 포지션 기준 HOLD / SELL / SKIP 판단 결과임.

Execution Plan으로 연결된 주문 후보는 Strategy Execution 화면에서 승인/전송 가능. Daily Signal 단계의 목표금액/수량은 비워두고, 실제 주문수량은 Execution 단계에서 계좌 현금과 현재가 기준으로 계산됨.
